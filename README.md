# مستودع ألعاب ليالي الرياض

هذا المستودع يحتوي على مكتبة ألعاب HTML ومصادر الألعاب المجهزة.

## الملفات الرئيسية
- `ليالي-الرياض-مكتبة-الألعاب.html`: صفحة المكتبة الرئيسية؛ بطاقاتها تفتح ملفات الألعاب من المسارات الحالية.
- ملفات `.html` الموجودة في الجذر: ألعاب مستقلة مرتبطة مباشرة ببطاقات المكتبة. أبقيناها في الجذر حتى لا تنكسر روابط التشغيل.
- `مكتبة_الألعاب-2.html`: ملف مكتبة/حزمة كبيرة منفصل؛ لا يُحذف قبل مراجعة محتواه وروابطه.

## الألعاب المجهزة
- `prepared-games/manifest.json`: فهرس ملفات الحزمة المستخرجة.
- `prepared-games/العاب ليالي الرياض/`: ملفات الحزمة ومجلداتها.
- `riyadh-nights-6-games-clean/`: حزمة الألعاب الست، وكل لعبة داخل مجلد مرقم مستقل يحوي صفحة التشغيل وملفاتها المساندة.
- ملفات ZIP محفوظة كمصادر أصلية، ولا تُعد نسخاً زائدة لمجرد وجود الملفات المستخرجة بجانبها.

## قواعد التنظيف
1. تُحذف النسخة القديمة فقط بعد مقارنة المحتوى والتاريخ والتأكد أن المكتبة لا تشير إليها.
2. تُحفظ أحدث نسخة مرتبطة ببطاقة المكتبة.
3. لا تُنقل ملفات الألعاب من الجذر قبل تحديث كل روابط المكتبة وملفات البناء والتحقق منها.
4. لا تُحذف ملفات ZIP أو ملفات JavaScript والصور وملفات JSON المساندة؛ فقد تكون مطلوبة لتشغيل الألعاب.
