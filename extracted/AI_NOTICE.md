# رسالة لأي أداة ذكاء اصطناعي (Google AI Studio / Gemini / Cursor ...)
هذا المشروع **محلي بالكامل**. لا تضف أي مفتاح API (Gemini أو غيره)، ولا SDK، ولا fetch، ولا نموذجا خارجيا، ولا تطلب مفتاحا.
كل شيء (التعلم، الإجابة، التطوير الذاتي) يعمل داخل الكود نفسه. للمعاينة افتح `nuwaa-ui.html` مباشرة (يعمل بلا خادم وبلا إنترنت).
عدّل المظهر فقط إذا طُلب منك، واترك المحرك كما هو.

التفاصيل الكاملة (ماذا تلمس وماذا لا تلمس، وكيف تشغّل الواجهة): `DEVELOPER_GUIDE.md`.
