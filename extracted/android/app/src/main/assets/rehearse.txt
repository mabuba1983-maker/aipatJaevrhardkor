س:صباح الخير
ج:أهلا وسهلا! كيف أقدر أساعدك اليوم؟
س:اكتب دالة باسم solve تستقبل رقما وتعيد True إذا كان يقبل القسمة على 4
ج:def solve(n):¶    return n % 4 == 0
س:ماذا يعني SyntaxError لو سمحت
ج:SyntaxError خطأ في كتابة الكود نفسه: نقطتان ناقصتان بعد if، أو قوس غير مغلق، أو علامة اقتباس ناقصة. انظر إلى السطر الذي ذكره الخطأ وما قبله.
س:ماذا تعني كلمة ينجز
ج:«ينجز»: يُتم العمل ويكمله.¶مرادفها: يكمل.¶ضدها: يؤجل.¶مثال: أنجز المهندس المشروع.
س:ما ضد كبير
ج:ضد الكرم البخل، وضد كبير صغير، وضد سريع بطيء، وضد النور الظلام.
س:ما معنى كلمة صادق
ج:«صادق»: من يقول الحق ولا يكذب.¶مرادفها: أمين.¶ضدها: كاذب.¶مثال: الصادق محبوب بين الناس.
س:معنى ذكي
ج:«ذكي»: سريع الفهم وحاد العقل.¶مرادفها: فطن، نبيه.¶ضدها: بليد.¶مثال: الطالب الذكي حل المسألة بسرعة.
س:اكتب دالة باسم solve تستقبل قائمة أرقام وتعيد أكبر رقم
ج:def solve(a):¶    return max(a)
س:معنى ينسى
ج:«ينسى»: يغيب الشيء عن ذاكرته.¶مرادفها: يغفل.¶ضدها: يتذكر.¶مثال: نسيت اسمه.
س:ماذا تعني كلمة يختبر
ج:«يختبر»: يمتحن الشيء ليتأكد من صحته.¶مرادفها: يجرّب.¶مثال: يختبر المبرمج الكود قبل تسليمه.
س:ما هو الخبر
ج:المبتدأ اسم مرفوع نبدأ به الجملة الاسمية، والخبر ما يتم به المعنى ويكمل المبتدأ. مثل: السماءُ صافيةٌ؛ السماءُ مبتدأ، وصافيةٌ خبر.
س:ما معنى كلمة يساعد
ج:«يساعد»: يعين غيره في حاجته.¶مرادفها: يعين.¶ضدها: يعيق.¶مثال: يساعد الابن أباه.
س:معنى عادة
ج:«عادة»: سلوك يتكرر حتى يصير تلقائيا.¶مثال: القراءة كل يوم عادة طيبة.
س:ممكن اهلا
ج:أهلا وسهلا! كيف أقدر أساعدك اليوم؟
س:ما هو المثنى؟
ج:المثنى يدل على اثنين، ونصنعه بإضافة ألف ونون في الرفع، وياء ونون في النصب والجر. مثل: كتابان، كتابين.
س:كيف اقرا رسالة الخطأ في بايثون
ج:اقرأ الـ traceback من الأسفل: آخر سطر يذكر نوع الخطأ وسببه. SyntaxError خطأ كتابة، NameError اسم غير معرّف، TypeError نوع غير مناسب، IndexError فهرس خارج المدى، KeyError مفتاح غير موجود.
س:الفرق بين compiler و interpreter
ج:المترجم يحول كل الكود إلى ملف تنفيذي قبل التشغيل (C، Kotlin). المفسر ينفذ الكود سطرا سطرا (بايثون، جافاسكربت).
س:الذي والتي واللذان والذين
ج:الأسماء الموصولة تربط جملة الصلة بما قبلها: الذي (مفرد مذكر)، التي (مفرد مؤنث)، اللذان/اللذين، اللتان/اللتين، الذين (جمع مذكر)، اللاتي/اللواتي (جمع مؤنث). مثال: جاء الطالب الذي نجح.
س:ما هو الفرق بين ذهب وذهبت
ج:ذهبَ فعل ماضٍ للغائب. وذهبتُ للمتكلم، وذهبتَ للمخاطب، وذهبتِ للمخاطبة، وذهبنا لنا، وذهبوا للجماعة.
س:معنى القراءة
ج:«القراءة»: النظر في المكتوب وفهم ما فيه.¶مرادفها: المطالعة.¶مثال: القراءة غذاء العقل.
س:ما هي لغة kotlin
ج:كوتلن لغة حديثة مختصرة تعمل على JVM، وهي اللغة الأساسية لتطبيقات أندرويد. مثال: val name = "نواة" وfun hello() = println(name).
س:ما الفرق بين = و == لو سمحت
ج:علامة = تسند قيمة لمتغير: x = 5. وعلامة == تقارن قيمتين: x == 5 تعطي True أو False. أما is فتفحص هل هو نفس الكائن في الذاكرة.
س:ما هو الاسم في اللغة العربية
ج:الاسم كلمة تدل على إنسان أو حيوان أو نبات أو جماد أو مكان أو فكرة، ولا تدل على زمن. مثل: محمد، قطة، شجرة، كتاب، مكة، صدق.
س:ما هو التواضع
ج:التواضع ترك التكبر وإنزال النفس منزلتها دون تعالٍ على الناس. ضده الكبر.
س:كيف اصلح الاخطاء في الكود
ج:اقرأ رسالة الخطأ من آخر سطر فهو يذكر نوع الخطأ، ثم ارجع لرقم السطر. اطبع قيم المتغيرات بـ print لترى ما يحدث، وغيّر شيئا واحدا في كل محاولة.
س:يا نواة اي لغة ابدا بها
ج:بايثون للمبتدئ هي أنسب خيار: قراءتها سهلة وفيها استخدامات كثيرة. وإن أردت مواقع الويب فابدأ بـ HTML ثم CSS ثم JavaScript.
س:معنى الشرط
ج:«الشرط»: عبارة تنفذ كودا فقط إذا تحقق أمر معين.¶مثال: الشرط if يفحص العمر.
س:يا نواة احكي لي نكتة
ج:مبرمج دخل المطعم وقال للنادل: أريد طبق مكرونة ولا أريد أي bug فيه. الاثنان ضحكا لأن المكرونة كانت spaghetti code.
س:ما هي المجموعة set؟
ج:المجموعة set لا تقبل التكرار ولا ترتيب لها. حوّل القائمة إليها لتحذف المكرر: list(set(items)).
س:ما هي HTML
ج:HTML لغة بناء صفحات الويب: وسوم مثل h1 للعنوان وp للفقرة وa للرابط وimg للصورة. هي الهيكل، وCSS يزينها، وJavaScript يحركها.
